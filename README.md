TaskFlow – Smart Productivity Platform

About the Project

TaskFlow is a smart productivity platform designed to help users organize their daily tasks and improve productivity through a simple and user-friendly interface.

Features

- Clean and modern user interface
- Dashboard preview
- Task management overview
- Multiple pricing plans
- Contact form
- Responsive design for different screen sizes

Technologies Used

- HTML
- CSS
- JavaScript

Project Structure

- "index.html" – Website structure
- "style.css" – Website styling
- "script.js" – Website interactions

How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your browser.

Project Purpose

This project was developed as part of a Front-End Development Internship assignment to demonstrate HTML, CSS, and JavaScript skills.
